# 커피 취향 질문지

AI에게 커피 취향을 어떻게 말할지 모르는 사람에게, 그대로 보낼 질문을 만들어 주는 앱입니다.

바탕 논문: [같은 커피 취향을 다르게 말하면 AI의 원두 추천도 달라질까?](https://github.com/SCA-cloudy/ALEPH-Thesis-Coffee-AI)

## 앱 한 문장

AI에게 커피 취향을 어떻게 표현할지 고민하는 사람이 원두를 물어보기 전에, 이 앱이 "취향 5가지를 모두 담으면 말투가 달라도 추천이 거의 같았다"는 논문 결과를 써서 그대로 보낼 질문을 만들어 줍니다.

## 사용자가 할 일 세 가지

| 할 일 | 왜 하는가 | 앱에서 하는 행동 | 예시 |
|---|---|---|---|
| 1. 내 말로 취향 적기 | 전문 용어를 몰라도 자기 말에서 시작할 수 있게 합니다. | 글 칸에 평소 말투로 취향을 적고 "내 말 읽기"나 Enter를 누릅니다. 다시 읽으면 앞서 읽은 답은 지워지고, 직접 고른 답은 남습니다. | "군고구마 같은 커피가 좋아요" |
| 2. 빠진 칸 채우기 | 논문에서 5가지를 모두 담은 문장은 말투가 달라도 추천이 거의 같았습니다. 그래서 말투를 고치는 대신 5가지를 다 담습니다. | 앱이 미리 골라 둔 답(파란 동그라미)을 확인해 다르면 바꾸고, 비어 있는 칸은 직접 고릅니다. | 비어 있는 여운에서 "적당히"를 고릅니다. |
| 3. 질문을 복사해 AI에게 보내기 | 앱의 목적은 AI에게 그대로 보낼 질문을 만들어 주는 것이고, 원두 추천은 AI에게 받습니다. | 자세히, 키워드, 빗대어 중 편한 말투를 고르고 "질문 복사"를 누른 뒤, AI 대화창에 붙여 넣어 보냅니다. | 완성된 질문으로 원두 5가지를 추천받습니다. |

## 실행 방법

1. 이 폴더의 `index.html`을 더블클릭합니다.
2. 브라우저에서 열리면 바로 쓸 수 있습니다.

설치할 것도, 로그인도, 환경 변수도 없습니다. 인터넷이 없으면 글꼴만 기본 글꼴로 바뀌고 기능은 그대로입니다.

## 논문 결과를 쓰는 곳

| 앱에서 하는 일 | 논문의 근거 |
|---|---|
| 산미, 향, 과일, 여운, 쓴맛 다섯 칸을 채우게 함 | 시험한 문장 3종이 모두 담은 취향 5요소 |
| 말투 세 가지로 질문을 만듦 | 표 5의 문장 3종. 시험한 취향을 고르면 논문 문장과 글자까지 같음 |
| 말투는 편한 것으로 고르라고 안내 | 표 8. 평균 겹침 3.85~4.02개, 기준선과의 차이 0.14개 이내 |
| 시험한 취향일 때 자주 나온 원두를 보여 줌 | 표 11을 말투 구분 없이 합친 값 |
| 확인하지 못한 것을 화면에 표시 | 4.5절 한계 |

## 논문에 없고 작성자가 판단한 것

- 다섯 칸 안의 보기. 논문은 한 가지 취향만 시험했습니다.
- 일상 표현의 제안 값. 예를 들어 군고구마는 "캐러멜과 꿀", 대추는 "흑설탕과 건과일 계열"로 제안합니다.
- 여운은 사람마다 느끼는 정도가 달라 일상 표현에서 제안하지 않고 직접 고르게 했습니다.

보기와 제안 값은 SCA 기준을 그대로 옮긴 것이 아닙니다.

## 데이터와 비밀값

- 앱에 들어간 데이터는 논문의 집계 숫자와 AI 응답에서 집계한 원두 이름뿐입니다. 개인정보는 없습니다.
- 입력한 내용은 브라우저 안에서 단어 규칙으로만 읽고 어디로도 보내지 않습니다.
- AI를 호출하지 않으므로 API 키와 환경 변수가 필요 없습니다.

## 처음 써 본 사람의 감상

이름은 적지 않았습니다.

- 동료(최종 판): 질문을 만들어 주는 데서 그치지 않고, AI가 바로 판단해 원두 5가지 추천까지 보여 주면 좋겠다.
- 커피에 관심이 많은 친구(수정 전 판): 취향대로 넣으니 좋아하는 원두가 나왔고, 추천 5가지 덕분에 다른 원두도 도전해 볼까 하는 생각이 들었다.
- 커피 표현을 잘 모르는 친구(수정 전 판): 커피의 맛과 향을 이렇게까지 생각해 본 적이 없어서 흥미로웠다.

수정 전 판은 2번 안내 문장, 다시 읽기, Enter로 읽기를 고치기 전의 판입니다.

## 아쉬운 점과 다음에 해 볼 것

- AI 추천까지 바로 보여 주기 (동료 제안): 만든 질문을 AI에 바로 보내 원두 5가지 추천까지 화면에 보여 주는 기능입니다. 이 앱의 목적은 AI에게 보낼 질문을 만드는 것까지이고, AI를 직접 부르려면 API 키와 그 키를 숨길 서버가 필요합니다. 또 추천이 입맛에 맞는지는 논문이 확인하지 않은 부분이라 이번에는 넣지 않았습니다.
- 다양한 표현 이해하기: "가을 같은 커피", "박카스 같은 커피", "탄산과 잘 어울리는 커피"처럼 사람들의 표현은 끝이 없어, 단어 목록으로는 다 담을 수 없습니다. 지금은 입력을 AI가 아니라 단어 규칙으로 읽고, 알아듣지 못한 표현이면 2번의 다섯 가지 질문으로 이어 줍니다. 앱 안에서 AI가 표현을 직접 이해하는 기능은 API 키와 서버가 필요해 다음에 해 볼 것으로 남겼습니다.
